## ✦ About

**QuoteQuest** is a small Python project that combines **web scraping and a
guessing game**.

It collects quotes and their authors from a public website using
**Beautiful Soup**, stores the extracted data in CSV format, and uses the
collected data to create a simple quote-guessing experience.

> Can you guess who said it? 👀

---

## ✨ Features

- 🌐 Scrapes quotes from a public website
- 🔍 Extracts quote and author information using Beautiful Soup
- 💾 Stores scraped data in CSV format
- 🎯 Uses collected data for a guessing game

## 🚀 Getting Started

### Prerequisites

Make sure you have **Python 3.x** installed.

### 1. Clone the repository

```bash
git clone https://github.com/PoojaRani24/QuoteQuest.git
```

### 2.Navigate to the project

```bash
cd QuoteQuest
```

### 3. Install dependencies
```bash
pip install requests beautifulsoup4
```

### 4. Run the project
```bash
python web_scraping_project1.py
```
